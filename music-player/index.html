            Iestatījumi

            Kā dabūt atslēgu (bez maksas, 3 min)
            1. Atver console.cloud.google.com un ielogojies ar Google kontu.
            2. Augšā izveido jaunu projektu (jebkāds nosaukums).
            3. Meklē “YouTube Data API v3” → spied Enable.
            4. Credentials → Create credentials → API key. Nokopē atslēgu (sākas ar AIza…).
            5. Ielīmē šeit un spied Saglabāt. Bez maksas ~100 meklēšanas dienā.
